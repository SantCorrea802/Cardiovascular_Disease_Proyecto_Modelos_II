# Cardiovascular Disease Prediction Project

This repository contains the course project for predicting cardiovascular disease using exploratory data analysis (EDA), preprocessing techniques, and classification models. The work follows the IEEE Transactions format and is organized into three main folders.

## Repository Structure

- **EDA_preprocessing/**  
  Contains notebooks and scripts for exploratory data analysis and preprocessing.  
  Includes steps such as variable renaming, age conversion, BMI feature engineering, outlier removal, and categorical encoding.

- **dataset/**  
  Contains the raw dataset used in the project (Kaggle Cardiovascular Disease dataset).  
  Data is organized and prepared for training, validation, and testing splits.

- **Informe/**  
  Contains the academic report in IEEE format.  
  Includes sections on problem description, dataset composition, selected ML paradigm, and state of the art.
